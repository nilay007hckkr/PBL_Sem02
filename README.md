# LCS - Loan Calculator System

## 📌 Project Overview

The **Loan Calculator System (LCS)** is a menu-driven C program developed as part of Semester 02 Project-Based Learning (PBL).
It enables users to calculate different types of loans, including interest, processing fees, and total payable amount.

The system provides a simple and efficient terminal-based interface for performing loan-related calculations.

---

## 🎯 Objectives

* To understand the implementation of structures and functions in C
* To apply financial and mathematical concepts like interest calculation
* To build a user-friendly console-based application
* To simulate real-world loan processing systems

---

## 🛠️ Features

* Supports multiple loan types:

  * Personal Loan
  * Vehicle Loan
  * Home Loan
  * Business Loan
  * Industrial Loan
  * Educational Loan
  * Gold Loan
  * Agriculture Loan
  * Credit Card Loan

* Different calculation methods:

  * Standard Loan Calculation
  * Education Loan Calculation
  * Simple Interest Calculation
  * Credit Card Loan Calculation

* Cross-platform compatibility:

  * Works on both Windows and Linux systems

* Interactive menu-driven interface

## ⚙️ How to Run

### 🔹 On Windows

1. Open Command Prompt
2. Compile the code:

   ```
   gcc LMS.c -o LCS
   ```
3. Run the program:

   ```
   LCS.exe
   ```

### 🔹 On Linux / Mac

1. Open Terminal
2. Compile the code:

   ```
   gcc LMS.c -o LCS -lm
   ```
3. Run the program:

   ```
   ./LCS
   ```

---

## 🧮 How It Works

1. The program displays a list of loan types
2. User selects a loan option
3. Inputs required values (loan amount, duration, etc.)
4. The system calculates:

   * Interest
   * Processing Fee
   * Total Payable Amount
5. Results are displayed on the screen
